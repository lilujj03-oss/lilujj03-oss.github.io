# 七逃趣氣象網站（原七逃行）｜對話重點紀錄

> 日期：2026-08-23
> 本文件為使用者與 AI 協作開發的重點節錄，不是完整逐字稿。為保護帳號安全，API Key、登入資訊與不必要的本機細節均已省略。

## 1. 專案起點

使用者希望參考台灣即時氣象地圖，製作一個可以持續更新的新版網站，並特別要求保留舊網頁：

> 「幫我做一個每日更新的網站，範例如下……這個網頁可以支援隨時更新。」

> 「不要覆蓋之前的網頁，新增並另存一個新的網頁。」

開發方向因此確立為獨立的全端氣象儀表板，包含台灣地圖、測站即時資訊、歷史圖表、一週預報與手動更新功能。

## 2. 地圖與資料問題

初版地圖曾出現圖磚破碎、台灣島不夠明顯及資料區塊空白等情況。使用者提出：

> 「為何圖是破的？」

> 「把台灣島明顯顯示出來。」

> 「為何空白？」

處理重點包括：

- 將 Leaflet 地圖限制在台灣附近的合理邊界並提供「顯示全台」功能。
- 改用穩定的淺色地圖圖磚，保留 OpenStreetMap／CARTO 圖資標示。
- 後端 API 沒有資料時顯示清楚的等待或設定提示，而不是留下空白畫面。
- 顯示測站數、資料更新狀態與觀測時間，方便判斷資料是否正常。

## 3. 中央氣象署資料整合

使用者提供完整的全端系統需求，希望整合中央氣象署資料：

- `O-A0001-001`：氣象測站即時觀測。
- `O-A0002-001`：雨量站「過去 1 小時雨量」。
- `F-D0047-091`：各縣市未來一週預報。

後端使用 FastAPI，資料以 SQLite 保存；前端使用 Leaflet 地圖與 Plotly 圖表。API Key 僅存放在本機 `.env`，不寫入前端，也不提交至 GitHub。

使用者曾詢問：

> 「為何不須使用 API Key？」

實際做法是由後端代為呼叫中央氣象署 API。瀏覽器只連線到本專案的 `/api`，因此不會在網頁原始碼中暴露授權碼。

## 4. 執行環境與連接埠排除

Windows 曾顯示找不到 Python：

> 「Python was not found……」

因此改用專案虛擬環境中的 Python：

```powershell
.\.venv\Scripts\python.exe backend\api.py
```

之後又遇到 `WinError 10048`，代表 8000 連接埠已有另一個伺服器程序。處理方式是確認既有程序、避免重複啟動，或改用另一個連接埠。

## 6. 自動更新與雨量規格

使用者要求：

> 「此網站要能做到自動更新。」

> 「雨量每小時偵測一次，抓 8 小時，單位一律改成 0～50 mm。」

完成規格如下：

- 後端每 60 分鐘自動同步氣象、雨量與一週預報資料。
- 啟動時若資料已過期，會自動補抓；右上角按鈕仍可手動更新。
- 雨量採用 `O-A0002-001` 的 `Past1hr/Precipitation`，單位為 mm。
- 同一測站、同一小時只保存一筆雨量資料，避免手動重整造成重複時次。
- 雨量趨勢最多顯示最近 8 個小時。
- 雨量圖縱軸固定為 `0–50 mm`，每 10 mm 一格。
- 如果氣象測站沒有相同代碼的雨量站，系統會以座標配對最近的雨量站並顯示來源。

新安裝的系統會從第一筆資料開始累積，持續執行滿 8 小時後即可看到完整 8 小時序列。

## 9. 部署後互動地圖修正

作品介紹頁發布至 Vercel 後，使用者回報：

> 「此地圖無法放大縮小。」

檢查後確認該區原本是儀表板的靜態 PNG 實測截圖，因此看起來像地圖，但不具備 Leaflet 的操作能力。修正方式如下：

- 作品介紹頁預設嵌入真正的線上互動氣象地圖。
- 地圖支援 ＋／− 按鈕、滑鼠滾輪及行動裝置雙指縮放。
- 提供「全螢幕開啟」連結，避免 iframe 尺寸限制操作。
- 原始實測截圖移至可展開區塊，並可在新分頁查看原尺寸。

## 13. 修正線上觀測日期與同步時間

使用者發現按下「更新觀測資料」後，畫面仍不是今天日期與現在時間。實測確認台北時間已是 `2026/08/23`，但舊代理 API 最新觀測停在 `2026/07/08`，因此不是時區或日期格式問題，而是上游資料庫已過期。

修正內容：

- 重新向中央氣象署抓取資料，最新觀測更新至 `2026/08/23 20:00`。
- 前端逐站比較觀測時間，較舊來源不得覆蓋較新的官方快照。
- 頁首分開顯示「最新觀測時間」與「本次同步時間」。
- 「同步最新資料」按鈕會跳過瀏覽器快取並重新讀取最新快照。
- 過期歷史、預報及 AI 結果不再顯示，以免舊日期造成誤解。
- 官方一週預報一併寫入快照，代理 API 過期時仍能顯示今天起的預報。
- 新增 GitHub Actions 每小時排程；CWA 授權碼只從 Repository secret `CWA_API_KEY` 讀取。
