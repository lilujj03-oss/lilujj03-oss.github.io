中央氣象署 (CWA) API 設定

本平台支援直接介接交通部中央氣象署「O-A0003-001 自動氣象站-氣象觀測資料」開放資料 API。

如何取得 CWA 授權碼？
1. 前往 中央氣象署氣象資料開放平臺 註冊會員（免費）。
2. 登入後至「會員專區」複製您的「API 授權碼」。
3. 貼上至上方欄位並點選儲存。金鑰儲存於您的本機瀏覽器（LocalStorage）。
